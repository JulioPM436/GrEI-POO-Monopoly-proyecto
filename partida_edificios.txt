# =====================================================================
#  PARTIDA DE PRUEBA DE EDIFICIOS - MONOPOLY ETSE PARTE 2
#  Uso: comandos partida_edificios.txt
#
#  - Las líneas que empiezan por # son comentarios: el lector de ficheros
#    tiene que saltarlas.
#  - Dos jugadores con los dados forzados, así que la partida sale siempre
#    igual. Pedro se hace con el grupo negro (Solar1-Solar2) y Maria con
#    el de Solar6-Solar8, y entre los dos construyen casas, hoteles,
#    piscinas y pistas de deporte. Las cifras están calculadas con un
#    simulador de las reglas del enunciado.
#  - Nadie cae en Suerte, Caja, impuestos, Cárcel, IrCarcel ni Parking,
#    ni en propiedades del otro: el dinero solo se mueve al comprar,
#    edificar y pasar por la Salida.
#  - IDs: un contador por tipo para toda la partida, que nunca se
#    reutiliza. Para la pista de deporte el enunciado no da ejemplo de ID:
#    aquí sale como pistadeporte-N. Si usáis otro prefijo, cambia solo eso.
#  - Supuestos donde el enunciado no es claro:
#      * Al edificar el hotel, las 4 casas desaparecen y no se devuelve
#        su dinero.
#      * En listar edificios <grupo>, el alquiler de cada solar es la suma
#        de los alquileres de sus edificios, sin el alquiler base.
#      * El grupo de Solar6-Solar8 (rosa en el tablero del enunciado) se
#        llama morado. Si en vuestro Tablero tiene otro nombre, cámbialo
#        en los listar edificios morado.
#  - Los mensajes de error no están fijados por el enunciado: lo que
#    importa es que no se edifique nada y que la fortuna no cambie.
# =====================================================================
